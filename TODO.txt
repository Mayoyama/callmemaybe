what does it mean performance optimisations?

The PDF says "caching, batching" specifically.

Caching — storing the logits for a prompt you've already seen so you don't re-run the model if the same prompt comes up again. Simple dict keyed on the prompt string.

Batching — processing multiple prompts through the model simultaneously rather than one at a time. Harder to implement because the SDK's get_logits_from_input_ids takes a single input, so you'd need to check if it supports batched input at all.

Caching alone would be quick (maybe an hour) and is a legitimate optimization. Batching depends entirely on what the SDK exposes.
